# 🌟 Nithya | Personal Portfolio Website

A personal portfolio website built for **Nithya**, a First-Year Computer Science and Engineering (CSE) student at **SNS College, Coimbatore**.

Designed with a modern **blue and white** color palette, clean typography, interactive animations, and responsive mobile-first architecture.

---

## 🚀 Sections Included

1. **Home**: Hero banner with dynamic typewriter effect, avatar with floating achievement badges, introduction, quick action buttons, and social handles.
2. **About Me**: Student journey at SNS College Coimbatore, key highlights, animated stat counters, and four core strengths (logical thinking, web design, continuous learner, teamwork).
3. **Skills**: Categorized skill cards featuring animated progress bars and tech badges:
   - Programming Languages (C, Python, JavaScript, Java Fundamentals)
   - Web Development (HTML5, CSS3, Flexbox/Grid, Responsive Design)
   - Tools & Workflow (Git, GitHub, VS Code, Linux CLI, Chrome DevTools)
   - Soft Skills & Engineering Mindset (Problem Solving, Collaboration, Time Management)
4. **Education**: Interactive vertical timeline detailing:
   - B.E. Computer Science & Engineering @ SNS College, Coimbatore (2025 – 2029)
   - Higher Secondary Certificate (HSC / 12th Grade)
   - Secondary School Leaving Certificate (SSLC / 10th Grade)
5. **Projects**: Showcase of academic and personal coding projects with category filtering (`All`, `Web Development`, `C & Python`) and popup detail modals:
   - Student Record Management System (C / File Handling)
   - Personal Portfolio Website (HTML5, CSS3, JavaScript)
   - Interactive CSE Quiz Application (JavaScript DOM)
   - Python Math & Matrix Utility (Python 3)
6. **Contact**: Interactive contact form with real-time validation, success notifications, college location badge, and social links.

---

## 🛠️ Built With

- **HTML5**: Semantic tags (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **CSS3**: Modern CSS Variables, Flexbox, CSS Grid, Glassmorphism, animations (`@keyframes`), and responsive media queries
- **JavaScript (ES6+)**: Typewriter animation, ScrollSpy, mobile hamburger menu, interactive project filter, contact form validation, modal windows, and back-to-top functionality
- **Icons & Fonts**: Font Awesome 6 + Google Fonts (Poppins & Inter)
